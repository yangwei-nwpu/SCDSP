# Objective-weight sensitivity

This directory supports the sensitivity analysis of the unit tardiness cost `c` for representative Set A, B, and C instances.

`WSensiti1/`, `WSensiti10/`, `WSensiti20/`, `WSensiti30/`, `WSensiti40/`, and `WSensiti50/` contain results for `c = 1, 10, 20, 30, 40, 50`. `weightAnalysis.ipynb` processes those files, and the PDF is the resulting figure for Online Supplement Section OS.5.2.
