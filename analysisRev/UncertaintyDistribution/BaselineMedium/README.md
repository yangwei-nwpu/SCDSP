# Baseline policies: medium uncertainty

This directory contains Det, EDT, and MTG baseline-policy evaluations under the main arrival-deviation setting `Tri(-6, 6, 0)`.

- `BaselinePolicyMedium.zip` is the complete archive.
- Extracted `*_SimDet.txt`, `*_SimEDD.txt`, `*_SimMAG.txt`, and corresponding log files are retained for direct analysis.

The names EDD and MAG in the implementation correspond to the EDT and MTG policies in the paper.
