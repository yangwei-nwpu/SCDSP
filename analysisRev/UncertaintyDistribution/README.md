# Arrival-uncertainty sensitivity

This directory contains baseline-policy and SimHGS outputs under three triangular arrival-deviation distributions:

- low: `Tri(-3, 3, 0)`
- medium: `Tri(-6, 6, 0)`
- high: `Tri(-9, 9, 0)`

`BaseLow/`, `BaselineMedium/`, and `BaseHigh/` contain Det, EDT, and MTG baseline evaluations. `SimHGSLow/` and `SimHGSHigh/` contain SimHGS outputs for low and high uncertainty; the main `results/SimHGS/` outputs provide the medium setting. These files support Online Supplement Section OS.5.1.
