# Benchmark instances

This directory contains the 72 SCDSP instances generated for the paper: 24 problem sizes for each of Sets A, B, and C.

## File names

Files follow `TDSP<nI>_<dI>_<nO>_<dO>_<suffix>.txt`. In this archive `nI = nO` and `dI = dO`.

| Suffix | Set | Data characteristics |
| --- | --- | --- |
| `M` | A | Sparse flow matrix with density 0.3 and baseline arrival distributions. |
| `MD` | B | Fully dense flow matrix with baseline arrival distributions. |
| `X` | C | Fully dense flow matrix with concentrated arrival distributions. |

The 24 size/door combinations range from 10 inbound and 10 outbound trucks with 3 doors on each side to 100 inbound and 100 outbound trucks with 15 doors on each side.

## Text format

Blank lines separate these blocks:

1. `|I| |O| |DI| |DO|`: inbound trucks, outbound trucks, inbound doors, and outbound doors.
2. `Q`: maximum load capacity.
3. The `|DI| x |DO|` door-distance matrix.
4. `|I| + |O|` truck rows: nominal arrival, expected departure, latest departure, and processing duration.
5. The `|I| x |O|` goods-flow matrix.
6. The `|I| x |O|` penalty-coefficient matrix.

The parser in [`../src/InstanceLib.cpp`](../src/InstanceLib.cpp) is the authoritative machine-readable specification.

Positive goods flows are sampled from `U[6,60]`, penalty coefficients from `U[15,25]`, and processing times from `U[5,10]`. Set C compresses the arrival ranges. Door distances use Manhattan distance on a rectangular layout. Full definitions appear in Table OS.1 of [`../OnlineSupplement.pdf`](../OnlineSupplement.pdf).
