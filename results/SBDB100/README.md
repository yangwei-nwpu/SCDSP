# Best-improvement simulation-based descent

This directory contains results for the best-improvement simulation-based descent comparator, denoted SBDB in the paper.

The method evaluates neighborhoods with 100 in-search scenarios and does not use the proposed fast evaluation technique. Each instance has `*_sol.txt` and `*_solSim.txt` outputs. Filename suffixes identify Sets A (`M`), B (`MD`), and C (`X`).
