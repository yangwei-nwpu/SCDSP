# Traditional simheuristic results

This directory contains outputs for TSim, the traditional simheuristic comparator in Section 6.2 of the paper.

Each instance has a `*_sol.txt` policy/solution file and a `*_solSim.txt` simulation-evaluation file. `TSim.tar.gz` is a compressed copy of the result collection. The reported comparison uses 10 independent runs and common out-of-sample evaluation settings.
