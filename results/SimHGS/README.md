# SimHGS results

This directory contains the proposed SimHGS outputs for all 72 instances.

- `*_sol.txt`: policies, door sequences, start times, objective values, and runtimes from independent runs.
- `*_solSim.txt`: scenario-based evaluations and summary statistics.
- `*_Bestlog.txt`: records the out-of-sample simulated objective value of the policy corresponding to the best solution.

The suffixes `M`, `MD`, and `X` correspond to Sets A, B, and C. These files support the main comparisons, policy evaluation, and robustness analyses.
